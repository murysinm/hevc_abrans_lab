# x265_abrans

Форк кодера x265, в котором модуль энтропийного кодирования CABAC заменён на алгоритм адаптивного двоичного rANS (ABrANS). Интерфейс командной строки и параметры кодирования остаются идентичными оригинальному x265.

## Сборка

Для сборки необходимы CMake и C++-компилятор с поддержкой C++11.

```bash
cd build/linux
cmake -G "Unix Makefiles" ../../source
make -j$(nproc)
```

Исполняемый файл `x265` появится в директории, из которой запускался CMake (`build/linux/x265`).

## Использование

Реализация не поддерживает многопоточный режим. В остальном интерфейс командной строки идентичен оригинальному x265. Пример кодирования из y4m:

```bash
./x265 --no-wpp -F 1 --frame-threads 1 --qp 22 --input test_data/akiyo_cif.y4m --output out.265

```

Дополнительные параметры кодирования передаются в той же форме, что и в оригинальном кодеке. Полная документация доступна на [x265.readthedocs.org](http://x265.readthedocs.org/).
